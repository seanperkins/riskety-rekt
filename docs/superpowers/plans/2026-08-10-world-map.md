# World Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One committed world of real geography, from which `season-init` selects a contiguous sub-map sized to the roster that actually joined — so a 15-person season can finally be dealt.

**Architecture:** A pure-data world (`src/map/world.ts`) plus a seeded selector (`src/map/select.ts`) that walks outward through whole continents until the size satisfies `checkDeal`. `RISK_MAP` is untouched and stays the golden file's fixture. Coordinates live in a separate lookup so the engine stays geometry-free and the golden file stays stable. A generated HTML viewer is the instrument for the geographic accuracy review, which no test can perform.

**Tech Stack:** TypeScript 5.x strict (`noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`), Vitest, Node 24, tsx. No new dependencies.

## Global Constraints

- **No new runtime dependencies.** `@slack/bolt` and `@slack/web-api` remain the only two.
- **`src/engine/` imports nothing outside itself.** `src/engine/types.test.ts` enforces this and bans `Date.now()`, `Math.random()`, `new Date()`. `src/map/` may import engine types; the engine may **not** import `src/map/`.
- **`RISK_MAP` is not modified.** It is `createSeason`'s default and the golden file's fixture. Any change to it regenerates `src/engine/__golden__/season-1.json`.
- **Never edit a shipped migration** in `src/store/schema.ts`; append a new one. This plan adds none.
- **Continents are 4–9 territories.** Enforced by `validateMap`.
- **`MIN_CONTINENTS = 4`, `MAX_ATTEMPTS = 20`**, both in `src/config.ts`.
- **`checkDeal` window is unchanged**: 5–11 territories per faction, 4–15 factions.
- Tests never touch the network — `test/no-network.ts` replaces `fetch` globally.
- `npm test` and `npm run typecheck` must pass at every commit.

## Spec deltas, decided before implementation

Two numbers in the spec were estimates that the actual decomposition corrected. The spec is updated in Task 14.

1. **World size is ~235 territories in ~46 continents**, not the spec's 165–175 / 26–30. Writing out the actual decomposition — real countries at Risk granularity, continents capped at 9 — lands there and no amount of trimming gets near 170 without making continents that are two countries wide. The number was an estimate and the decomposition is the measurement, so the estimate loses. The *bands the tests assert* become **220–250 territories and 42–50 continents**.

   Nothing in the design depends on the smaller number. Storage is 30 KB per state row and 0.44 MB per season, still negligible. A season uses a subset either way — a larger world just means more distinct boards. The one real cost is authoring, and that cost is the same whether or not the plan admits it up front.
2. **The viewer precomputes boards rather than running the selector in the browser.** The spec said selection would run client-side. There is no bundler in this project ("nothing is compiled or bundled"), so shipping `select.ts` to the browser would mean hand-duplicating the algorithm in JS — two implementations that can disagree. Instead the build script precomputes ~96 boards and inlines only *which continents each selected*; the page reconstructs the sub-map from the world with about ten lines of filtering. Same interaction, no duplicated algorithm. `select.ts` still uses no Node APIs.

```ts
/** A deterministic PRNG. Seeded, so seasons and boards replay exactly. */
export type Rng = () => number

/**
 * xorshift32 — deterministic for a seed, so seasons replay exactly.
 *
 * Two corrections, both measured rather than assumed:
 *
 * The middle shift is `>>>`, not `>>`. JS bitwise operators coerce to *signed*
 * int32, so once the state passes 2^31 a `>>` sign-extends and folds ones into
 * the high bits — a different map from xorshift32, with no reason to believe it
 * keeps the full period.
 *
 * And the generator is warmed up. From a small seed, xorshift32's first output
 * is nearly linear in it: seeds 1..200 produced first draws of 0.000063,
 * 0.000126, 0.000189 ... — 200 out of 200 in the bottom quarter. The simulator
 * seeds seasons sequentially, so every season's first decision was drawn from
 * the same sliver, and a seeded Fisher-Yates picked j = 0 for its first swap
 * regardless of seed. Discarding the first outputs costs nothing and the state
 * is fully mixed by then.
 */
export function makeRng(seed: number): Rng {
  let s = seed >>> 0 || 1
  const step = (): number => {
    s ^= s << 13
    s >>>= 0
    s ^= s >>> 17
    s ^= s << 5
    s >>>= 0
    return s / 0x1_0000_0000
  }
  for (let i = 0; i < 16; i++) step()
  return step
}
```

Also move `shuffle` out of `src/jobs/season-init.ts`, verbatim including its docstring:

```ts
/**
 * Fisher-Yates, seeded. The engine holds no randomness by design, so the
 * shuffle happens here and the seed goes in `seasons.seed` — that is what makes
 * a deal reproducible after the fact.
 */
export function shuffle<T>(items: T[], rng: Rng): T[] {
  const out = [...items]
  for (let i = out.length - 1; i > 0; i--) {
    const j = Math.floor(rng() * (i + 1))
    const a = out[i]!
    const b = out[j]!
    out[i] = b
    out[j] = a
  }
  return out
}
```

```ts
import { CONTINENT_MAX, CONTINENT_MIN } from "../config.js"
import type { ContinentId, GameMap, TerritoryId } from "../engine/index.js"

export type MapProblem =
  | { kind: "duplicate-territory"; id: TerritoryId }
  | { kind: "self-loop"; id: TerritoryId }
  | { kind: "duplicate-neighbor"; id: TerritoryId; neighbor: TerritoryId }
  | { kind: "unknown-neighbor"; id: TerritoryId; neighbor: TerritoryId }
  | { kind: "asymmetric"; id: TerritoryId; neighbor: TerritoryId }
  | { kind: "unknown-continent"; id: TerritoryId; continent: ContinentId }
  | { kind: "empty-continent"; continent: ContinentId }
  | { kind: "continent-size"; continent: ContinentId; size: number }
  | { kind: "continent-split"; continent: ContinentId }
  | { kind: "disconnected"; reachable: number; total: number }

/** Every territory reachable from `start`, walking only within `within`. */
function reach(
  start: TerritoryId,
  byId: Map<TerritoryId, { neighbors: TerritoryId[] }>,
  within: Set<TerritoryId> | null,
): Set<TerritoryId> {
  const seen = new Set([start])
  const queue = [start]
  while (queue.length > 0) {
    for (const n of byId.get(queue.pop()!)?.neighbors ?? []) {
      if (seen.has(n)) continue
      if (within !== null && !within.has(n)) continue
      if (!byId.has(n)) continue
      seen.add(n)
      queue.push(n)
    }
  }
  return seen
}

/**
 * Structural checks on a map. Returns EVERY problem rather than throwing on the
 * first, because a hand-authored world has several on its first pass and fixing
 * them one run at a time is miserable.
 *
 * This cannot check geography. "Chad borders Egypt" is symmetric, connected,
 * in-band and wrong -- that is what the viewer is for.
 */
export function validateMap(map: GameMap): MapProblem[] {
  const problems: MapProblem[] = []
  const byId = new Map(map.territories.map((t) => [t.id, t]))
  const continentIds = new Set(map.continents.map((c) => c.id))

  const seenIds = new Set<TerritoryId>()
  for (const t of map.territories) {
    if (seenIds.has(t.id)) problems.push({ kind: "duplicate-territory", id: t.id })
    seenIds.add(t.id)

    if (!continentIds.has(t.continent)) {
      problems.push({ kind: "unknown-continent", id: t.id, continent: t.continent })
    }

    const seenNeighbors = new Set<TerritoryId>()
    for (const n of t.neighbors) {
      if (n === t.id) {
        problems.push({ kind: "self-loop", id: t.id })
        continue
      }
      if (seenNeighbors.has(n)) {
        problems.push({ kind: "duplicate-neighbor", id: t.id, neighbor: n })
        continue
      }
      seenNeighbors.add(n)
      const other = byId.get(n)
      if (other === undefined) {
        problems.push({ kind: "unknown-neighbor", id: t.id, neighbor: n })
      } else if (!other.neighbors.includes(t.id)) {
        problems.push({ kind: "asymmetric", id: t.id, neighbor: n })
      }
    }
  }

  for (const c of map.continents) {
    const members = map.territories.filter((t) => t.continent === c.id)
    if (members.length === 0) {
      problems.push({ kind: "empty-continent", continent: c.id })
      continue
    }
    if (members.length < CONTINENT_MIN || members.length > CONTINENT_MAX) {
      problems.push({ kind: "continent-size", continent: c.id, size: members.length })
    }
    const within = new Set(members.map((t) => t.id))
    if (reach(members[0]!.id, byId, within).size !== members.length) {
      problems.push({ kind: "continent-split", continent: c.id })
    }
  }

  const first = map.territories[0]
  if (first !== undefined) {
    const reachable = reach(first.id, byId, null).size
    if (reachable !== map.territories.length) {
      problems.push({ kind: "disconnected", reachable, total: map.territories.length })
    }
  }

  return problems
}
```

  for (const n of t.neighbors) {
    const key = [t.id, n].sort().join("|");
    if (drawn.has(key) || !coords[n]) continue;
    drawn.add(key);
    parts.push(\`<line class="edge" x1="\${sx(coords[t.id].lon)}" y1="\${sy(coords[t.id].lat)}" x2="\${sx(coords[n].lon)}" y2="\${sy(coords[n].lat)}"/>\`);
  }
}

  const c = coords[t.id];
  parts.push(\`<circle class="terr" cx="\${sx(c.lon)}" cy="\${sy(c.lat)}" r="5" fill="\${colorOf[t.continent]}"><title>\${t.name} — \${t.continent}\\nborders: \${t.neighbors.join(", ")}</title></circle>\`);

}

  const n = world.territories.filter(t => t.continent === c.id).length;
  return \`<tr><td><span class="swatch" style="background:\${colorOf[c.id]}"></span>\${c.name}</td><td>\${n}</td></tr>\`;

  \`<tr><td>continents</td><td>\${world.continents.length}</td></tr>\`;
</script></body></html>`

writeFileSync("viewer/map.html", html)

import { MIN_CONTINENTS } from "../config.js"
import { checkDeal } from "../season.js"
import { makeRng } from "../rng.js"
import { validateMap } from "./validate.js"
import { WORLD } from "./world.js"
import { selectSubMap } from "./select.js"

describe("selectSubMap", () => {
  it("produces a legal, valid board for every roster size and many seeds", () => {
    // The property that matters. checkDeal is what refuses a board at
    // season-init, so a selector that can produce one it rejects is broken.
    for (let factions = 4; factions <= 15; factions++) {
      for (let seed = 1; seed <= 25; seed++) {
        const map = selectSubMap(WORLD, factions, makeRng(seed))
        const label = `${factions} factions, seed ${seed}`
        expect(validateMap(map), label).toEqual([])
        expect(checkDeal(factions, map.territories.length), label).toBeNull()
        expect(map.continents.length, label).toBeGreaterThanOrEqual(MIN_CONTINENTS)
      }
    }
  })

  it("is deterministic for a seed, and varies across seeds", () => {
    const ids = (seed: number) =>
      selectSubMap(WORLD, 11, makeRng(seed)).territories.map((t) => t.id)
    expect(ids(4711)).toEqual(ids(4711))
    expect(ids(4711)).not.toEqual(ids(4712))
  })

  it("selects whole continents, never part of one", () => {
    // A half-continent makes its bonus meaningless -- an objective you complete
    // by holding three of six real territories is not the mechanic.
    const map = selectSubMap(WORLD, 9, makeRng(31))
    for (const c of map.continents) {
      const inWorld = WORLD.territories.filter((t) => t.continent === c.id).length
      const inMap = map.territories.filter((t) => t.continent === c.id).length
      expect(inMap, c.id).toBe(inWorld)
    }
  })

  it("drops neighbours that were not selected", () => {
    // Otherwise the induced map fails its own symmetry invariant.
    const map = selectSubMap(WORLD, 6, makeRng(77))
    const ids = new Set(map.territories.map((t) => t.id))
    for (const t of map.territories) {
      for (const n of t.neighbors) expect(ids.has(n), `${t.id} -> ${n}`).toBe(true)
    }
  })

    // place would corrupt WORLD for every later season in the same process --
    // which is exactly what the simulator does, 2000 times.
    const before = JSON.stringify(WORLD)
    selectSubMap(WORLD, 12, makeRng(5))
    expect(JSON.stringify(WORLD)).toBe(before)
  })

  it("computes a bonus for every continent, and none is zero", () => {
    const map = selectSubMap(WORLD, 10, makeRng(9))
    for (const c of map.continents) expect(c.bonus, c.id).toBeGreaterThanOrEqual(1)
  })

  it("reproduces classic Risk's bonus on a hand-checked shape", () => {
    // floor(size/2) + floor(entries/3). Australia: 4 territories, 1 entry -> 2.
    expect(bonusFor(4, 1)).toBe(2)   // Australia
    expect(bonusFor(4, 2)).toBe(2)   // South America
    expect(bonusFor(9, 3)).toBe(5)   // North America
    expect(bonusFor(12, 5)).toBe(7)  // Asia
  })

```ts
import { MAX_ATTEMPTS, MIN_CONTINENTS } from "../config.js"
import type { ContinentId, GameMap, Territory } from "../engine/index.js"
import type { Rng } from "../rng.js"

/**
 * A continent's bonus.
 *
 * `floor(size / 2) + floor(entries / 3)`, calibrated against classic Risk,
 * which it reproduces exactly on four of six continents and misses by one on
 * Africa and Europe -- in opposite directions, so it is not systematically
 * generous or stingy.
 */
export function bonusFor(size: number, entries: number): number {
  return Math.max(1, Math.floor(size / 2) + Math.floor(entries / 3))
}

/**
 * A contiguous sub-map sized to the roster.
 *
 * Whole continents only: a half-continent makes its bonus meaningless. Bonuses
 * are computed HERE and not carried in the world data, because a continent's
 * defensibility depends on which of its neighbours were selected -- Northern
 * Africa with Southern Europe and Western Asia on the board has three ways in;
 * on a board with neither it is a fortress.
 */
export function selectSubMap(world: GameMap, factionCount: number, rng: Rng): GameMap {
  const lo = 5 * factionCount
  const hi = 11 * factionCount
  const target = 7 * factionCount

  const members = new Map<ContinentId, Territory[]>()
  for (const c of world.continents) members.set(c.id, [])
  for (const t of world.territories) members.get(t.continent)?.push(t)

  const sizeOf = (id: ContinentId): number => members.get(id)?.length ?? 0

  // Continent adjacency, derived from borders rather than stored. A second
  // source of truth could drift from the territory records.
  const owner = new Map(world.territories.map((t) => [t.id, t.continent]))
  const adjacent = new Map<ContinentId, Set<ContinentId>>()
  for (const c of world.continents) adjacent.set(c.id, new Set())
  for (const t of world.territories) {
    for (const n of t.neighbors) {
      const other = owner.get(n)
      if (other !== undefined && other !== t.continent) {
        adjacent.get(t.continent)?.add(other)
      }
    }
  }

  const starts = world.continents.map((c) => c.id)

  for (let attempt = 0; attempt < MAX_ATTEMPTS; attempt++) {
    const picked = new Set<ContinentId>([starts[Math.floor(rng() * starts.length)]!])
    let size = sizeOf([...picked][0]!)

    while (size < lo || picked.size < MIN_CONTINENTS) {
      const candidates: ContinentId[] = []
      for (const c of picked) {
        for (const n of adjacent.get(c) ?? []) {
          if (!picked.has(n) && size + sizeOf(n) <= hi) candidates.push(n)
        }
      }
      if (candidates.length === 0) break // stranded; restart from a new seed continent

      // Nearest to target, ties broken by rng so the walk is not
      // deterministically greedy in one direction.
      const best = [...new Set(candidates)].sort(
        (a, b) =>
          Math.abs(size + sizeOf(a) - target) - Math.abs(size + sizeOf(b) - target) ||
          (a < b ? -1 : 1),
      )
      const near = best.filter(
        (c) => Math.abs(size + sizeOf(c) - target) === Math.abs(size + sizeOf(best[0]!) - target),
      )
      const chosen = near[Math.floor(rng() * near.length)]!
      picked.add(chosen)
      size += sizeOf(chosen)
    }

    if (size >= lo && size <= hi && picked.size >= MIN_CONTINENTS) {
      return induce(world, picked, members)
    }
  }

  throw new Error(
    `selectSubMap: no board for ${factionCount} factions in ${MAX_ATTEMPTS} attempts ` +
      `(needed ${lo}-${hi} territories from >= ${MIN_CONTINENTS} continents)`,
  )
}

function induce(
  world: GameMap,
  picked: Set<ContinentId>,
  members: Map<ContinentId, Territory[]>,
): GameMap {
  const kept = world.territories.filter((t) => picked.has(t.continent))
  const ids = new Set(kept.map((t) => t.id))

  // Copies, never the world's own records. Filtering neighbours in place would
  // corrupt WORLD for every later season in the same process -- which is what
  // the simulator does, 2000 times.
  const territories: Territory[] = kept.map((t) => ({
    ...t,
    neighbors: t.neighbors.filter((n) => ids.has(n)),
  }))

  const continents = [...picked]
    .sort()
    .map((id) => {
      const source = world.continents.find((c) => c.id === id)!
      const size = members.get(id)?.length ?? 0
      const entries = (members.get(id) ?? []).filter((t) =>
        t.neighbors.some((n) => ids.has(n) && !members.get(id)!.some((m) => m.id === n)),
      ).length
      return { ...source, bonus: bonusFor(size, entries) }
    })

  return { continents, territories }
}
```
